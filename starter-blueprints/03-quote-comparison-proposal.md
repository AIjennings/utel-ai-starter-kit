# Blueprint 03: Multi-Vendor Quote Comparison & Executive Proposal
**Workflow:** Drop in raw Telarus / AppDirect / supplier quotes → Get an executive comparison table + ready-to-send client recommendation.

---

## Copy-Paste Prompt

```markdown
Act as a Senior Technology Advisor at Utel USA following our AGENTS.md security and citation standards.

### MY END-STATE VISION ("THE FINISHED KITCHEN"):
I am attaching/pasting quotes from multiple suppliers (via Telarus / AppDirect / carrier direct). Turn this raw quote data into a clean, executive-ready **Vendor Comparison & Recommendation** that a CEO, CFO, or IT Director can approve in 3 minutes.

### BUILD THESE 4 SECTIONS NOW:

1. **Executive Summary & Bottom-Line Recommendation:**
   - Current state vs. proposed state in 3 bullet points
   - Total Monthly Savings & 36-Month Contract Savings

2. **Side-by-Side Supplier Comparison Matrix:**
   | Location / Service | Current Spend | Option A (Carrier + Spec) | Option B (Carrier + Spec) | Option C (Carrier + Spec) | Term & NRC | Source Citation |

3. **Why We Recommend the Winner (Pros / Tradeoffs / SLAs):**
   - Compare install intervals, fiber path diversity, SLA uptime/credits, and contract flexibility.

4. **Draft Client Email (`[DRAFT — FOR HUMAN APPROVAL]`):**
   - A concise, high-confidence email presenting the options without overwhelming the client.

### STRICT ACCURACY & SECURITY RULES:
- Cite the exact quote document and line item for every rate.
- Strip any internal TSB/Master Agent commission or SPIFF columns (Yellow Tier data) so they NEVER appear in client-facing tables.
```
